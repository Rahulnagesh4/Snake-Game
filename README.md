# Snake-Game
This project is a classic Snake Game developed using Python’s built-in turtle graphics module. The game recreates the traditional snake gameplay where the player controls a growing snake to collect food while avoiding collisions with the walls and its own tail.

# 🐍 Snake Game (Python)

A classic Snake Game built using Python's **turtle graphics** module. Control the snake, eat the food, grow longer, and try not to crash!

---

## 🎮 Gameplay

- Use **arrow keys** to move the snake:
  - ⬆️ Up
  - ⬇️ Down
  - ⬅️ Left
  - ➡️ Right
- Eat the food to grow longer
- Avoid hitting:
  - The walls
  - Your own tail
- Game ends when a collision occurs

---

## 🚀 Features

- Smooth snake movement
- Real-time score tracking
- Snake grows after eating food
- Collision detection (walls & self)
- "Game Over" display
- Clean and modular code (OOP-based)

---

## 🛠️ Technologies Used

- Python 🐍
- Turtle Graphics 🎨
- Object-Oriented Programming (OOP)
